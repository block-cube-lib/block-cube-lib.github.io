git mergeでコンフリクトしたときにどちらかのファイルで上書きする(restore)

2026/09/14 23:11 公開
git

git mergeでコンフリクトしたときにどちらかのファイルで上書きするの内容のcheckoutではなくrestoreを使用する版です。

git merge <branch-name>

したときにファイルがコンフリクトして解決する方法

手元のファイル優先

git restore --ours <conflicted-file>

マージするブランチのファイル優先

git restore --theirs <conflicted-file>
